# PerformersSongs

## Описание проекта

**PerformersSongs** — настольное приложение для управления музыкальными исполнителями и их песнями. Приложение разработано на платформе .NET MAUI с использованием C# и базы данных SQLite.

## Функциональные возможности

- Просмотр списка музыкальных исполнителей.
- Добавление новых исполнителей.
- Редактирование информации об исполнителях.
- Удаление исполнителей.
- Просмотр списка песен выбранного исполнителя.
- Добавление новых песен.
- Редактирование информации о песнях.
- Просмотр подробной информации о песне.
- Удаление песен.
- Хранение данных в локальной базе данных SQLite.

## Используемые технологии

- C#
- .NET 9
- .NET MAUI
- XAML
- Entity Framework Core
- SQLite
- MediatR
- CQRS
- Repository Pattern
- Unit of Work
- Dependency Injection

## Архитектура проекта

Решение разделено на четыре проекта:

| Проект | Назначение |
|---|---|
| PerformersSongs.Domain | Доменные сущности и бизнес-модель |
| PerformersSongs.Application | DTO, команды, запросы и логика приложения |
| PerformersSongs.Infrastructure | Работа с базой данных, репозитории и реализация доступа к данным |
| PerformersSongs.Presentation | Пользовательский интерфейс на .NET MAUI и XAML |

## Запуск приложения

1. Склонировать репозиторий:

   ```bash
   git clone https://github.com/Vivi123097543/PerformersSongs.git
   ```

2. Открыть файл `PerformersSongs.sln` в Visual Studio 2022.
3. Убедиться, что установлена поддержка разработки приложений .NET MAUI.
4. Выполнить восстановление пакетов NuGet.
5. Выбрать проект `PerformersSongs.Presentation`.
6. Выбрать конфигурацию запуска Windows Machine и запустить приложение.

## Платформа

Приложение предназначено для запуска на Windows.
